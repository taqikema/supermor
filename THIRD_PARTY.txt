Known source and input attribution for the planned release
========================================================

custEM
------
The research kernels were developed in the sibling custEM research repository
at commit 016d934cd4ae7411db5e579cb11ba22bce2ac296, then extracted into the
independent supermor package. The existing LGPLv3/GPL license text remains
in LICENSE.rst. Preserve applicable original author/copyright notices.
No upstream custEM source is bundled; the official unmodified dependency is
https://gitlab.com/Rochlitz.R/custEM.git at commit
be0ef8729761a7eae32ababc8b362514d84f5f0a (custEM 1.7.0).
The copied upstream VERSION.rst and framework modules have been removed.
SUPERMOR's own package version is defined in pyproject.toml.

COMET
-----
Official custEM imports COMET through its profiler even when profiling is off.
The external, unmodified COMET dependency is pinned in environment.yml;
its source is not bundled in the SUPERMOR distribution.

MR3D
----
The manuscript cites the original resistivity model by Carvalho and
Menezes (2017), DOI: https://doi.org/10.5281/zenodo.400233, and identifies
its license as CC BY 4.0. Preserve the source record, exact downloaded file
names, selected version, attribution and preprocessing description for any
material inputs or derived section data actually distributed.

Dependencies and fonts
----------------------
Third-party software dependencies keep their own licenses. Refer to the
versions actually used in ENVIRONMENT.txt; this scaffold does not bundle
their source, binaries or licenses as a new combined distribution.
The existing drawing style expects Times New Roman. Document a supported
font source/substitution; no system font files are included in this folder.

Authors' newly published data
-----------------------------
No new data license is selected by this scaffold. Before release, state the
license for authors' own mesh/plotting datasets and preserve any applicable
third-party conditions. This note does not replace that final declaration.
